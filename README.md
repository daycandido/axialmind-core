## Executar localmente

Pré-requisito: Node.js + npm ([instalação com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
npm install
npm run dev
```

## Scripts disponíveis

- `npm run dev` — ambiente de desenvolvimento
- `npm run build` — build de produção
- `npm run test` — testes com Vitest
- `npm run lint` — lint com ESLint
